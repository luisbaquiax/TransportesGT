# TransportesGT
Plataforma que permita a una empresa de transporte extraurbano de Guatemala controlar, entre otras cosas, la compra de boletos de bus, el registro de buses, el alquiler de buses para viajes privados, choferes, horarios de salida, costos de combustible, depreciación de bus por viaje y gastos de taller y repuestos
